Context & Industry Challenges

Problem Statement & Motivation

The Attack Vector

Over 90% of cyber breaches begin with email phishing. Threat actors employ sophisticated deception like brand typosquatting, IDN homographs, and disguised double extensions that bypass traditional spam filters.

The Manual Bottleneck

SOC analysts receive hundreds of alerts daily. Triage requires manually reading raw RFC 822 text files, checking SPF/DKIM records, and querying 5+ disconnected tabs (VirusTotal, URLhaus, AbuseIPDB).

Average time per email: 15–20 minutes.

The Solution

An automated investigation workbench that ingests raw .eml files or headers, decomposes components, scans for anchor spoofing and payload entropy, and delivers a complete dossier in under 2 seconds.

Scope & Goals

Project Objectives & Scope

01 Email Header Forensics & Route Tracing

Parse RFC 822 multipart MIME structures, reconstruct chronological relay hops across Received: headers, and evaluate SPF, DKIM, and DMARC alignment status.

02 Anchor Text Spoofing & Hyperlink Audit

Audit all HTML anchor tags to catch visual spoofing where display text says paypal.com but the destination points to an unauthorized external IP host.

03 Deep Binary & Attachment Inspection

Inspect magic bytes (detecting MZ PE executables, PDFs, ZIPs), flag disguised double extensions (.pdf.exe), and compute Shannon entropy for packed malware.

04 MITRE ATT&CK® & Audit Reporting

Correlate indicators with official MITRE Enterprise techniques (T1566, T1036, T1059), generate an incident timeline, and export self-contained HTML audit reports.

Mathematical & Security Logic

Key Algorithms Embedded in Code

Anchor Text Spoofing Detector

Compares the domain token in visible link text against the actual destination hostname:

claimed_domain = extract_domain(display_text) actual_domain = urlparse(href).netloc if claimed_domain != actual_domain: return True # ANCHOR_TEXT_SPOOF (+30 pts)
Shannon Entropy Calculation

Measures binary byte randomness ($0.0$ to $8.0$). Payloads exceeding $7.1$ indicate packing/encryption:

H(X) = - Σ (P(x_i) * log2(P(x_i))) if entropy > 7.1: flag_packed_payload() # Malware evasion
Levenshtein Distance Lookalikes

Calculates minimum edit operations to detect brand impersonation completely offline:

dist = levenshtein_distance(domain, brand) if 1 <= dist <= 2 or brand in domain: flag_typosquatting() # e.g. update-paypal.cc
Weighted Risk Scoring Engine

Point-based evaluation with strict security ceilings:

Score = SPF_fail(25) + DKIM_fail(20) + Anchor_spoof(30) + Executable(35) + URLhaus_hit(40) Verdict: >= 70 MALICIOUS | >= 35 SUSPICIOUS | < 35 BENIGN
